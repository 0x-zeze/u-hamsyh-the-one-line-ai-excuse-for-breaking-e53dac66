## Run

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes the single-line UTF-8 entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output/entry.txt`).
